# Selected Work: Frontend and UI/UX

Four web projects, each a self-contained page that runs without a build step.

**Live:** https://lamanhkhoi.github.io/ui-showcase/

| # | Project | Folder | Highlights |
|---|---|---|---|
| 01 | Prisca Vo, personal portfolio | [first_real_project](https://github.com/Lamanhkhoi/first_real_project) | Bilingual EN/VI, 6 routes, GSAP + Lenis |
| 02 | Selat, rail and sea freight | `freight/` | Scroll-scrubbed video hero, live shipment tracker |
| 03 | squish, cold-pressed juice | `juice/` | Colour-flood flavour slider, build-your-box cart |
| 04 | Nep Stays, boutique booking | `stays/` | Search, filters, gallery, checkout, .ics confirmation |

## Tech

HTML, CSS and vanilla JavaScript. GSAP 3.13 (ScrollTrigger), Lenis, Google Fonts. Responsive from 360px, keyboard accessible, respects `prefers-reduced-motion`.

## Run locally

```bash
python -m http.server 8000
# open http://localhost:8000
```

Brands in projects 02 to 04 are fictional. Photography: Unsplash; video and product cut-outs: MotionSites free library.
