# Prisca Vo, MBA - Personal Portfolio

Bilingual (English / Vietnamese) portfolio website for **Vo Thi Minh Phuong (Prisca), MBA**, Director of Global Sourcing and Business Lecturer, founder of **PHTSO (PH Transform Solution)**.

**Live site:** https://lamanhkhoi.github.io/first_real_project/

## Pages

| Route | Content |
|---|---|
| `#/` | Home: introduction, core strengths, services, working process, product categories |
| `#/about` | Profile, credentials, career milestones, values |
| `#/expertise` | Sourcez Academy, Global Sourcing Office, Supply Chain Consulting |
| `#/academy` | Courses and FAQ |
| `#/speaking` | Lecture topics and engagements |
| `#/contact` | Contact form, phone, email, LinkedIn, office map |

## Tech

- HTML, CSS, vanilla JavaScript in a single `index.html` (no build step)
- [GSAP](https://gsap.com/) with ScrollTrigger, SplitText and DrawSVG for scroll animation
- [Lenis](https://lenis.darkroom.engineering/) for smooth scrolling
- Fonts: Cormorant, Lato, Be Vietnam Pro (Google Fonts); icons: Phosphor
- Responsive from 360px to wide desktop, respects `prefers-reduced-motion`

## Run locally

```bash
python -m http.server 8000
# open http://localhost:8000
```

Opening `index.html` directly in the browser also works.
